# ya-salaam-videos
## Standing rules
- Every video must state the MEANING (the moral) of the proverb on screen: top banner + meaning card at the start, in simple English (and Arabic where possible). The literal word-for-word translation is only the joke, shown secondarily (e.g. end board).
- Captions lead with the Arabic proverb, then "المعني:" line with the moral.
